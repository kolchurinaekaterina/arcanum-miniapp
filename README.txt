АРКАНУМ — комплект для Render

1. Загрузите файлы index.html, server.py и render.yaml в приватный репозиторий GitHub.
2. В Render выберите New > Blueprint и подключите репозиторий.
3. Введите YANDEX_API_KEY и YANDEX_FOLDER_ID в секретных переменных Render. Не загружайте ключи в GitHub.
4. Проверьте публичную ссылку после развёртывания.

Лимит по умолчанию: до 100 запросов к ИИ в сутки на один запущенный процесс.
Это НЕ финансовый лимит: отдельно установите бюджетные ограничения в Yandex Cloud.
При перезапуске счётчик сбрасывается. Для публичного платного продукта
понадобятся постоянный учёт лимитов, антибот-защита и мониторинг расходов.
План free в render.yaml может требовать изменения в зависимости от условий Render.
